# Dataset Directory

- `sample_images/`: Contains sample test images included in the repository for immediate code execution and visual verification.
- `set100/` *(Not tracked in Git)*: Place the full 100-image benchmark dataset here to reproduce all paper tables and plots.

### Data Attribution
1. **Benchmark Subset (`set100`):** [Landscape Test Images on Kaggle](https://www.kaggle.com/datasets/juanbayonfernandez/landscape-test-images)
2. **Parent Dataset:** [Landscape Pictures Dataset on Kaggle](https://www.kaggle.com/datasets/arnaud58/landscape-pictures)
